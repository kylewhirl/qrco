# Roadmap

This project is early open-source software. The current focus is making the app, API, docs, and SDK easier to run, inspect, and contribute to.

## Near Term

- Improve local setup for contributors without production credentials.
- Add focused tests around API auth, QR rendering, and billing state.
- Reduce remaining dependency audit noise by tracking upstream fixes for Stack Auth and NextAuth.
- Document API route contracts next to the SDK types.
- Add example applications for SDK usage.

## Contribution Areas

- Documentation improvements
- SDK ergonomics
- QR rendering reliability
- Accessibility improvements
- Test coverage
- Deployment docs for self-hosting

Large product or billing changes should start with a discussion issue before implementation.
